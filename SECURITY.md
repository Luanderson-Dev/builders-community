# Política de Segurança

## Versões suportadas

| Versão | Suporte |
|---|---|
| `main` (desenvolvimento) | ✅ |

Projeto pré-lançamento: apenas a `main` recebe correções.

## Reportando vulnerabilidades

**Não abra issue pública.**

1. Envie e-mail para **contato@luanderson.dev.br**
2. Assunto: `[SECURITY] togetherdev-space`
3. Inclua: descrição, impacto estimado, passos de reprodução/PoC, ambiente

Resposta inicial em até **72 horas**. Após confirmação:

1. Correção desenvolvida em branch privado
2. Release com patch + aviso de segurança público
3. Crédito ao reporter (se desejar)

Por favor, dê tempo razoável para correção antes de divulgação pública.

## Escopo

Em escopo: código deste repositório (backend, frontend, configs de deploy).
Fora de escopo: dependências sem CVE aplicável ao uso, ataques que exijam acesso físico, spam/social engineering.
